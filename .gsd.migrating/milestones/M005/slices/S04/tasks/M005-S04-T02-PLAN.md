# M005-S04-T02: Implement JWT authentication module

## Why
JWT tokens provide stateless authentication with role claims. This module creates tokens for login and validates them on requests.

## Do
1. Create backend/auth.py:
   - SECRET_KEY and ALGORITHM config (from env, with defaults)
   - create_access_token(data: dict) function - encodes user_id and role into JWT
   - verify_token(token: str) function - decodes and validates JWT, returns user_id/role
   - get_current_user(token: str = Depends(oauth2_scheme)) dependency - extracts user from DB
   - oauth2_password_bearer scheme for Authorization header parsing
2. Add environment variable documentation for JWT_SECRET_KEY
3. Create TokenData schema for verified token payload

## Done when
- backend/auth.py exists with all required functions
- JWT creation and verification work with test data
- SECRET_KEY is configurable via environment

## Inputs

- `backend/models.py`
- `backend/database.py`
- `backend/schemas.py`

## Expected Output

- `backend/auth.py`
- `backend/schemas.py`

## Verification

grep -q 'create_access_token' backend/auth.py && grep -q 'verify_token' backend/auth.py && grep -q 'get_current_user' backend/auth.py

## Observability Impact

Token validation failures log specific error (expired, invalid, missing) for debugging
