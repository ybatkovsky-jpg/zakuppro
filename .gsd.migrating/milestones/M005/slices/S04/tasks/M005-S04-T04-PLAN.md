# M005-S04-T04: Create login endpoint and update main.py

## Why
Users need a way to authenticate and receive JWT tokens. The login endpoint validates credentials and returns a token.

## Do
1. Create backend/routers/auth.py:
   - POST /api/auth/login endpoint
   - Validate username/password against database
   - Hash password verification with passlib
   - Return access_token with role claim
2. Update backend/main.py:
   - Include auth router
   - Add JWT_SECRET_KEY to app.config or environment loading
   - Document auth endpoints in OpenAPI tags
3. Create test credentials for verification:
   - Document default owner user credentials in README or comments

## Done when
- POST /api/auth/login accepts username/password and returns JWT
- Login response includes access_token and role
- Invalid credentials return 401

## Inputs

- `backend/auth.py`
- `backend/rbac.py`
- `backend/models.py`
- `backend/main.py`

## Expected Output

- `backend/routers/auth.py`
- `backend/main.py`

## Verification

grep -q 'login' backend/routers/auth.py && grep -q 'auth.router' backend/main.py

## Observability Impact

Failed login attempts log username and IP address for security monitoring
