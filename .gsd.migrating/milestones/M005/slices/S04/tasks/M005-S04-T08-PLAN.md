# M005-S04-T08: Write RBAC integration tests and verify slice

## Why
RBAC is security-critical. Integration tests verify all role combinations work correctly and 403 responses are proper.

## Do
1. Create backend/tests/test_rbac_integration.py:
   - Test login endpoint returns valid JWT with role claim
   - Test each router with each role:
     - Owner token: full access to all endpoints
     - Manager token: only own projects, read-only suppliers, own analytics
     - Warehouse token: only stock items, 403 elsewhere
   - Test 403 responses have proper error format
   - Test ownership enforcement (manager can't access other manager's projects)
2. Create frontend test (if test framework exists):
   - Test login flow stores token
   - Test API client includes Authorization header
3. Update slice S04 verification:
   - Run integration tests: pytest backend/tests/test_rbac_integration.py -v
   - Manual verification: curl tests for each role
4. Document test credentials in S04-SUMMARY

## Done when
- Integration tests pass for all role combinations
- 403 responses verified for unauthorized access
- Slice verification passes

## Inputs

- `backend/auth.py`
- `backend/rbac.py`
- `backend/routers/projects.py`
- `backend/routers/stock_items.py`
- `backend/routers/suppliers.py`
- `backend/routers/analytics.py`

## Expected Output

- `backend/tests/test_rbac_integration.py`

## Verification

cd backend && python -m pytest tests/test_rbac_integration.py -v --tb=short 2>&1 | head -50

## Observability Impact

Test results document all verified role combinations. Failures show exact endpoint/role/permission triplet that failed.
