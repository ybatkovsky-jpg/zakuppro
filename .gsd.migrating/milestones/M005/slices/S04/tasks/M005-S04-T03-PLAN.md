# M005-S04-T03: Create RBAC authorization middleware

## Why
Authorization logic needs to be reusable across all routers. This module provides decorators and utilities for role-based access control.

## Do
1. Create backend/rbac.py:
   - require_role(allowed_roles: List[str]) dependency factory
   - require_ownership() function for resource ownership checks
   - get_current_active_user() dependency (verifies user is active if is_active field exists)
   - PermissionDenied exception (403) with structured error response
2. Document permission matrix in docstring:
   - owner: all endpoints
   - manager: own projects only, read-only suppliers
   - warehouse: stock items only, 403 elsewhere
3. Create utility functions for filtering queries by ownership:
   - apply_ownership_filter(query, model, user_id, user_role)

## Done when
- backend/rbac.py exists with require_role dependency
- require_ownership function exists for resource-level checks
- PermissionDenied exception returns 403 status

## Inputs

- `backend/auth.py`
- `backend/models.py`

## Expected Output

- `backend/rbac.py`

## Verification

grep -q 'require_role' backend/rbac.py && grep -q 'require_ownership' backend/rbac.py && grep -q 'PermissionDenied' backend/rbac.py

## Observability Impact

Authorization denials log user ID, role, endpoint, and required permission
