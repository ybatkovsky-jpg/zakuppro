# M005-S04-T05: Update projects router with RBAC enforcement

## Why
Projects router is the primary endpoint for managers. It needs ownership filtering and role-based access control.

## Do
1. Update backend/routers/projects.py:
   - Add current_user: User = Depends(get_current_user) to all endpoints
   - For list_projects: filter by owner_id if role is manager, return all if owner
   - For get_project: verify ownership (manager can only see own projects)
   - For create/update/delete: require_role(['owner', 'manager']) + ownership check
   - Return 403 for warehouse role (no access)
2. Update query logic:
   - Use apply_ownership_filter helper from rbac.py
   - Ensure consistent filtering across all CRUD operations
3. Add ownership check before update/delete operations

## Done when
- All project endpoints require valid JWT token
- Manager users can only access their own projects
- Warehouse users receive 403 on all project endpoints
- Owner can access all projects

## Inputs

- `backend/auth.py`
- `backend/rbac.py`
- `backend/routers/projects.py`

## Expected Output

- `backend/routers/projects.py`

## Verification

grep -q 'current_user' backend/routers/projects.py && grep -q 'require_role\|ownership' backend/routers/projects.py

## Observability Impact

Unauthorized access attempts log user ID, role, and requested project ID
